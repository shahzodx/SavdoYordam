# Дизайн-система v0.1

Реализация: `apps/mobile/lib/design_system/`. Цвета: primary #087F68, ink #17231F, muted #66756F, background #F7F9F8, border #E5ECE8, мягкий зелёный #E8F6F0; warning использует тёмный текст #835713 на #FFF3DC. Ошибка — текст с понятным объяснением, не один цвет.

Типографика — Noto Sans, локально включённый variable-шрифт с кириллицей и узбекской латиницей, лицензия OFL в assets/fonts. Display 34/700, heading 28/700, section 21/600 и 16/600, body 16 и 14 с высотой 1.45, label 14/600. Денежные показатели используют табличные цифры. Во время работы шрифт не загружается из сети.

Отступы 8/12/16/20/24; карточки radius 16–20, поля 12, кнопки 14. Главная карточка зелёная, остальной UI преимущественно нейтральный. Кнопки min-height 52; icon buttons и Material navigation используют стандартные touch targets. SafeArea, scrollable формы и keyboard insets обязательны.

Компоненты: AppButton, AppCard, MetricCard, ProductCard, SaleTile, EmptyState, StatusBadge, SectionHeading, DataView, FieldSpec/appForm. Loading — progress indicator; отдельного shimmer/skeleton пока нет. Ошибки — локализованный текст и retry. Синхронизация — pending/conflict с отдельными объяснениями.

Пять вкладок сохраняют состояние. «Новая продажа» — основная кнопка на главной и FAB на остальных вкладках. В POS нижняя зона содержит корзину и итог; ввод весового количества/платежа использует системную цифровую клавиатуру. Продажа подтверждается после проверки суммы и клиента. Полный возврат требует причины и объясняет, что деньги надо фактически вернуть покупателю отдельно.

Анимация — стандартные переходы Material/go_router и bottom sheet; нет тяжёлых эффектов. Тактильный отклик при добавлении и подтверждении. Увеличение текста 200% проверено для empty state, но ещё не для всех экранов. Полный аудит WCAG AA, TalkBack и физическое тестирование малых экранов остаются release gate.
